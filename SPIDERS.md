# The spiders: the nervous system

Item 18 of the owner's list, 2026-09-07. Recorded as architecture rather than as a ticket, with one label change that is a ticket.

## The role, as set

The spider federation graphs are **the nervous system of GlobalGrid2050**. Four duties, and they are not decorative:

1. **A backup to the grid engine.** If the engine is ever lost, the graph knows what it was made of, what depended on it and where the copies were.
2. **Neural links to the amnesia repository.** A cured fault becomes a vaccine there, and the graph is what connects a vaccine to the code it protects, so the cure is reachable from the thing it cures.
3. **A repository of maths and logic capsules.** The working engines were sealed today with their hashes and the eight rules that make them worth copying. The graph is where a capsule is found, not just stored.
4. **Reachable from the product.** It sits in the estate section of the About panel, beside the maths and the federation map, which is where a reader who wants to know how something is computed will actually look.

## The rule that keeps it useful

**It expands infinitely; the scope is what must be fixed.** A graph that grows without a bounded scope becomes a picture of everything and an answer to nothing. So the scope is set the way the amnesia repository sets its own: what is in scope is what a vaccine or a capsule needs to be reachable. Everything else is noise the graph may see but must not carry.

That is the discipline the owner set tonight, and it is the same one running through the cable engines and the bug register: **be precise about scope, and leave brute force to compute.** The architecture decides what is worth computing; the machines decide how fast. There is a whole grid to build, and it will not be built by grinding.

## It has already earned its keep

The sandbox shows an edge marked **DUPLICATES** between the engine's geodesy module and a second geodesy implementation in the maths repository. That is the same fault the external review found tonight by argument, and the same one that put our interconnector spans on a different earth radius from the rest of the estate.

**The graph found it structurally, before anyone measured a span.** A duplicate implementation of the one thing that must never disagree is exactly what a nervous system should feel. That single edge justifies the whole instrument, and it is an argument for making the graph a gate rather than a view: a duplicate of a canonical module should be a finding, not a node colour.

## Where it goes next, when there is compute

The owner's direction, recorded so the scope decision precedes the hardware: sentinels running on local machines with real memory, driven by both lanes, doing the wide sweeps that a session cannot. The order matters. **Scope and architecture first, brute force second.** A large machine pointed at an unbounded graph produces a larger picture of everything.
