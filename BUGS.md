### Composition note, and it changes how every report above should be read

Every owner report so far has been made against the **root** Atlas, which serves generation `202609060259`. Read from the live file, root loads: streaming-parquet-bridge v9.112, uk-gazetteer-flyto v9.112, sld-sandbox **v9.135**, substation-intelligence **v9.139**.

The version tested and shipped today, `202609071232`, is a **different set of cartridges** rather than merely newer ones: it carries place-global-search where root carries a gazetteer flyto, and its sld-sandbox is eleven versions further on. So a fault seen on root may already be absent on the lane, may be unrelated to anything changed today, or may sit in a cartridge root does not even load.

Nothing here should be fixed until each report has been retried on the lane version. Root promotion is the owner's decision, and it is now also the cheapest way to make the reports and the tests describe the same software.

## Rule for the next round

**GG-001 comes first and it is a measurement, not a fix, and it must run on iOS.** Every owner report is from an iPhone and no harness covers that platform, so the firing rate has to be measured where the faults are actually seen. Until there is a firing rate per case, measured online against the published version, cold and repeated, no intermittent ticket can be prioritised honestly and no fix can be shown to have worked. Every version after that changes exactly one thing, carries the test that failed before it, and leaves its predecessor standing as the control.
